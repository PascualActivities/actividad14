# 🤖 Portafolio de Soluciones en Inteligencia Artificial

Bienvenido al repositorio central de **cmcorrea_apps**. Este proyecto es una aplicación web interactiva desarrollada en **Streamlit** que reúne y presenta un catálogo de aplicaciones y demostraciones de **Inteligencia Artificial**, abarcando áreas como Visión Artificial, Procesamiento de Audio, Agentes Inteligentes, Sistemas Ciberfísicos y Modelos de Lenguaje (LLMs).

---

## 🚀 Proyectos Destacados

1. **Conversión de Texto a Voz (TTS)**: Síntesis de voz hiperrealista a partir de texto con soporte multimodal.
2. **Reconocimiento y Detección de Objetos**: Detección y clasificación en tiempo real usando **YOLOv5**.
3. **Entrenamiento de Modelos**: Laboratorio interactivo para transfer learning y prueba de modelos de Deep Learning.
4. **Conversión de Voz a Texto (STT)**: Reconocimiento del habla y traducción automática en tiempo real.
5. **Análisis de Datos con Agentes IA**: Exploración, análisis estadístico y visualización autónoma de datos con agentes.
6. **Transcriptor Inteligente Audio / Video**: Transcripción precisa multilenguaje basada en **OpenAI Whisper**.
7. **Generación en Contexto (RAG con PDF)**: Asistente conversacional con recuperación aumentada sobre documentos PDF.
8. **Análisis Multimodal de Imágenes**: Comprensión visual avanzada y razonamiento impulsado por **GPT-4o**.
9. **Sistemas Ciberfísicos & Percepción**: Integración de visión por computador en entornos físicos y sensórica IoT.

---

## 🛠️ Requisitos e Instalación

Para ejecutar este portafolio localmente en tu computadora:

1. **Clonar o descargar el repositorio**:
   ```bash
   git clone https://github.com/cmcorrea/cmcorrea_apps.git
   cd cmcorrea_apps
   ```

2. **Instalar las dependencias**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Iniciar la aplicación**:
   ```bash
   streamlit run Intro.py
   ```
